# Мой пет-проект

Идея: Телеграм-бот для ежедневного учета личных расходов с автоматической категоризацией.

Стек: Python, aiogram, SQLite, Docker.

Цель: Научиться разворачивать бота в контейнере, настроить CI/CD пайплайн для автодеплоя при пуше в main и освоить работу с базами данных внутри Docker.

Сроки реализации:

- Этап 1 (Проектирование и БД): до конца сентября
- Этап 2 (Написание бота): октябрь
- Этап 3 (Деплой в Docker и CI/CD): ноябрь
